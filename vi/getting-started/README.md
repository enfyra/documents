# Bắt đầu

Phần này hướng dẫn bạn cài đặt Enfyra, đăng nhập lần đầu, tạo dữ liệu và kiểm tra API sinh tự động.

Nếu mới dùng Enfyra, hãy đi theo thứ tự các trang dưới đây. Nếu instance của bạn đã chạy, dùng mục điều hướng nhanh để đến thẳng việc cần làm.

## Điều hướng nhanh

### Chuẩn bị

- **[Enfyra Cloud](../cloud/README.md)** — Chọn dịch vụ được quản lý nếu bạn không muốn tự vận hành server, database, Redis và quy trình triển khai.
- **[Cài đặt](./installation.md)** — Cài Enfyra bằng Docker hoặc thiết lập thủ công workspace app + server.
- **[Đăng nhập lần đầu và làm quen giao diện](./getting-started.md)** — Đăng nhập, nắm bố cục Admin và chọn bước tiếp theo.

### Bắt đầu từ một ứng dụng hoạt động

- **[Xây dựng ứng dụng đầu tiên](./first-app.md)** — Tạo collection công việc, thêm dữ liệu và gọi API sinh tự động trong khoảng 15 phút.

### Xây dựng model dữ liệu đầu tiên

- **[Tạo bảng dữ liệu](./table-creation.md)** — Tạo table, cấu hình field, khai báo relation và hiểu API được sinh ra.
- **[Quản lý dữ liệu](./data-management.md)** — Tạo, sửa, lọc và xóa bản ghi trong Admin.

## Lộ trình học

1. **[Cài đặt](./installation.md)** — Thiết lập một ứng dụng Enfyra.
2. **[Xây dựng ứng dụng đầu tiên](./first-app.md)** — Hoàn thành một vòng từ collection đến API.
3. **[Đăng nhập lần đầu và làm quen giao diện](./getting-started.md)** — Tìm hiểu các phần còn lại của Admin.
4. **[Tạo bảng dữ liệu](./table-creation.md)** — Đi sâu hơn vào field, relation, index và constraint.
5. **[Quản lý dữ liệu](./data-management.md)** — Làm việc với các bản ghi trong table bạn vừa tạo.
